# 职业规划与简历生成

## 核心流程

### 第一阶段：信息收集（提问式访谈）

逐题提问，一次只问一个问题，上限 15 题。每道题独立成组，获取明确回答后再进入下一题。达到 15 题上限或关键信息已完整时停止。

**标准 15 题清单（可按行业/岗位灵活调整措辞）：**

1. **当前行业与岗位** — 在哪个行业、做什么岗位？若在职则描述现况，若离职则描述上一份。
2. **工作年限与级别** — 在该领域累计多少年？总监/管理级别担任了多久？
3. **核心成果** — 主导过哪些关键项目？取得过什么量化成果？挑 2-3 个最有代表性的说。
4. **学历背景** — 学校、专业、学历层次（本科/硕士/博士），是否有 MBA 等进修经历？
5. **薪资期望** — 目前薪资范围？下一份工作期望薪资？
6. **工作地点偏好** — 是否限定某个城市或区域？
7. **行业偏好** — 继续深耕原行业还是开放拓展？具体偏好哪些行业？
8. **岗位方向偏好** — 偏技术管理、偏商务市场还是综合管理岗？哪些方向明确不考虑？
9. **公司类型偏好** — 国企/民企/外企/创业公司？规模偏好？是否有排斥的类型？
10. **团队管理经验** — 目前带领团队规模（直接下属 + 整体），团队职能构成。
11. **技术/专业能力** — 熟悉的技术平台、工具、编程语言、行业系统等。
12. **学历/进修细节** — 若在读，方向是什么？预计何时毕业？
13. **语言能力** — 英语或其他外语水平？是否有海外工作/学习经历？
14. **资质证书** — 专业资质、认证、行业奖项等。
15. **换工作动机** — 为什么想换？追求什么？（稳定、成长、薪资、平台、转型等）

**提问原则：**
- 一次只问一个问题，等待用户回答后再继续
- 如果用户回答已覆盖后续问题，跳过对应问题
- 问题措辞根据用户已提供信息动态调整，保持自然对话感

### 第二阶段：信息整理与画像输出

收集完信息后，整理输出"求职画像"汇总表，包含：
- 经验年限与轨迹
- 学历层次
- 核心亮点（量化成果）
- 团队规模
- 技术标签
- 求职偏好（地点/行业/公司类型/方向）

### 第三阶段：岗位搜索

基于画像进行多轮互联网搜索，搜索策略：

1. **第一轮** — 核心匹配：`[地点] [行业/岗位关键词] [级别] 招聘`
2. **第二轮** — 偏好匹配：根据用户公司偏好（国企/民企/外企）加限定词
3. **第三轮** — 扩展匹配：相邻岗位或更高层级的搜索

使用 WebSearch 工具执行搜索，每条结果提取：公司名、岗位名、地点、薪资、关键要求、公司性质。

将岗位分为三个推荐梯队：
- **第一梯队**：完美匹配用户偏好（地点+行业+公司类型）
- **第二梯队**：大部分条件匹配
- **第三梯队**：可关注但不完全匹配

特别标注即将截止的岗位和高度匹配的岗位。

### 第四阶段：简历生成

使用 `scripts/generate_resume.py` 生成 DOCX 格式简历。此脚本是一个模板化简历生成器，需要根据收集到的用户信息进行参数化填充。

**使用步骤：**

1. 确保 python-docx 已安装：
   ```bash
   pip install python-docx
   ```

2. 修改脚本中的以下关键参数，将 `[ ]` 占位符替换为用户实际信息：
   - 姓名、邮箱、手机、年龄
   - 当前/过往公司名称与时间
   - 教育背景的具体年份和院校
   - 个人概述中的经验年限和行业描述
   - 核心能力标签
   - 工作经历的工作内容描述
   - 荣誉与资质

3. 运行脚本生成 DOCX：
   ```bash
   python scripts/generate_resume.py
   ```

4. 使用 present_files 工具展示生成的简历文件。

**注意事项：**
- 简历中的具体项目描述和量化数据必须与用户提供的信息一致
- 保持简历专业风格，排版美观
- 未获取的信息用 `[ ]` 占位标记，而非编造
